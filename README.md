# RTSLytics

[![CI](https://github.com/ccsimplyspolit/AOE4-Analytics/actions/workflows/ci.yml/badge.svg)](https://github.com/ccsimplyspolit/AOE4-Analytics/actions/workflows/ci.yml)
[![Лицензия MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
![Платформа Windows](https://img.shields.io/badge/platform-Windows-blue.svg)

RTSLytics — настольный помощник для **Age of Empires IV**: разведка соперника,
мета цивилизаций, билды, оверлей, статистика матчей и локальный разбор реплеев.
Приложение работает поверх Electron + React и не вмешивается в процесс игры.

Основной принцип проекта — показывать только подтверждённые данные. Если API,
локальный файл или реплей недоступны, интерфейс выводит состояние `нет данных`,
`неизвестно` или явный пробел покрытия, а не подставляет нулевую или выдуманную
оценку.

## Возможности

- поиск любого игрока и просмотр его рейтинга, формы, цивилизаций, карт и личных
  матчапов;
- выбор любого игрока в матче: для каждого участника доступны цивилизация,
  профиль, статистика, билд-аудит и сравнение с эталоном;
- сравнение билдов по шагам, времени, ресурсам и совместимости цивилизации;
- кэширование истории, реплеев и сводок с повтором неудачных запросов;
- объединение локальной истории AoE4, AoE4World и авторизованной истории Relic;
- скачивание доступных онлайн-реплеев и полный локальный разбор `.rec`;
- вспомогательный локальный адаптер [AOEMods.Essence](https://github.com/aoemods/AOEMods.Essence)
  для атрибутов, RGD и нативных иконок;
- игровой оверлей: матчап, контр-юниты, билд, таймер, APM и послематчевый блок;
- локальный Stream Desk для OBS/Streamlabs;
- встроенные гайды, калькуляторы, викторины и тренер сочетаний клавиш.

## Вкладки приложения

Основная навигация задаётся одним маршрутизатором в
`src/renderer/main/nav.tsx`. Названия в коде оставлены стабильными для deep-link
ссылок, в интерфейсе они могут переводиться на русский.

| Вкладка | Маршрут | Что находится внутри |
| --- | --- | --- |
| **Dashboard** | `/` | Активный профиль, рейтинг и ранг по лестницам, пик рейтинга, процент побед, последние матчи, текущий матч и быстрые переходы в Scout, Replay Lab и разбор игры. |
| **My Stats** | `/stats` | Личная история матчей, фильтры по цивилизации, сопернику, карте, формату, результату, патчу и периоду; win rate, длительность, APM, ресурсы, тренды, сравнение выборок и история билд-аудита. Игры против ИИ и локальные тренировочные матчи можно исключить. |
| **Data Studio** | `/data-studio` | Лаборатория личных данных: фильтрованная выборка матчей, агрегированные метрики (win rate, длительность, ресурсы/мин), покрытие патчами и сезонами, реестр источников, время снимка, проверка и ручное обновление внешних снапшотов, статус Essence. |
| **Explorer** | `/explorer` | Офлайн-справочник игры и доказательств: юниты, здания, технологии, улучшения, патчи, публичные дампы, поиск видео и викторина. Есть фильтры по эпохе/цивилизации, карточка стоимости и времени, экспорт JSON/CSV и аудит покрытия патчами. |
| **Scout** | `/scout` | Поиск соперника по имени или AoE4World ID, лидерборды, рейтинг, форма, последние игры, любимые цивилизации и карты, личные head-to-head результаты, командные планы и live-мета текущего матча. |
| **Civ Meta** | `/civ-meta` | Актуальная мета по очереди, рангу, патчу и пулу карт. Внутренние разделы описаны ниже. |
| **Guides** | `/guides` | Библиотека гайдов и инструментов: гайды, строительные порядки, Counter Helper, Civ Quiz, Shortcut Trainer и Beasty Number. |
| **Tincture** | `/tincture` | Слой решений над локальными данными RTSLytics: сводка меты, калькулятор производства, Cellar/каталог билдов, редактор билдов и Match Coach. |
| **Replay Lab** | `/replays` | Локальный архив, аккаунтный архив AoE4World/Relic, скачивание и кэш реплеев, кэш сводок, повтор и полный разбор. |
| **Stream Desk** | `/stream` | Управление трансляцией: состав команд, счёт серии, таймер, spoiler guard, overrides имён/цивилизаций/рангов, CSS-тема и локальный browser source для OBS. |
| **Settings** | `/settings` | Внешний вид, профиль, интеграции, оверлей, опросы, статистика, горячие клавиши, Steam/Relic, replay parser и переводчик. |
| **About** | `/about` | Версия, лицензия, сведения о приватности, источниках и границах анализа. |

### Civ Meta

У `/civ-meta` есть пять deep-link разделов (`?tab=`):

1. **Tier list** — сортируемый тир-лист с размером выборки и фильтрами очереди,
   ранга и патча.
2. **Civ stats** — игры, pick rate, win rate и рейтинговые срезы по каждой
   цивилизации.
3. **Counter Lab** — направленная статистика матчапа, отдельно глобальная и
   локальная личная выборка; sample size всегда виден.
4. **Counter Calculator** — контр-юниты с учётом роли, эпохи, стоимости,
   времени обучения и состава отвечающей цивилизации. Это объяснимый список
   кандидатов, а не симулятор боя.
5. **Maps** — статистика цивилизаций по картам и текущий ranked map pool; пул
   обновляется с проверкой полноты и хранит последний валидный снимок при сбое
   сети.

### Guides

- **Guides** — вводные материалы и практические подсказки для новичков.
- **Build Orders** — локальный каталог, импорт RTS Overlay/`.overlay.json`,
  AoE4Guides и AOE4 Builds, фильтры по цивилизации, патчу, сезону, карте,
  источнику и видео, предпросмотр и сохранение provenance.
- **Counter Helper** — ответ на вопрос «что строить против обнаруженного юнита»
  с учётом возраста и ресурсов.
- **Civ Quiz** — викторина по цивилизациям и их признакам.
- **Shortcut Trainer** — локальная тренировка сочетаний клавиш: можно назначать,
  сохранять, проверять и повторять комбинации без чтения игры.
- **Beasty Number** — сводный показатель игрока по доступным матчам и профилю.

### Tincture

- **Decision Summary** — текущий снимок меты, покрытие билдов, движение
  показателей и ссылки в канонические разделы Civ Meta/Explorer.
- **Production Calculator** — непрерывные очереди производства, число зданий,
  целевые юниты в минуту, пользовательские скорости сбора, скидки, пассивный
  доход, цивилизационные модификаторы и импорт состава из билда.
- **Cellar** — личное хранилище билдов и доказательств: происхождение,
  автор/видео, патч, тайминги, заметки, импорт/экспорт JSON/CSV и deep-link.
- **Build Builder** — редактор шага, времени, ресурсов, возраста, требований и
  заметок; результат сохраняется в совместимой структуре RTS Overlay.
- **Match Coach** — сводка выбранного игрока матча, карта/патч/состав,
  совместимые билды и рекомендации. Он не объявляет публичный payload доказанным
  билдом, если в нём нет наблюдаемой последовательности действий.

### Replay Lab: что именно разбирается

1. **Local archive** индексирует локальные `matchhistory` и найденные
   `replay.rec`, включая игры без файла реплея.
2. **Account archive** загружает полную историю AoE4World и обогащает её слотами
   Relic. Страница остаётся постраничной, а полный снимок хранится локально.
3. **Cache available** скачивает доступные `.rec`; **Cache all** и **Cache all
   summaries** обрабатывают архив возобновляемыми пачками по 50 элементов.
4. **Analyze replay** декодирует заголовок и поток `game tick → block → command`,
   показывает игроков, команды, очереди производства, окна активности, gaps,
   APM и покрытие парсера.
5. **Download + full analysis** выполняет скачивание, получение `stats.rgs` и
   декодирование одной cache-first операцией. Кнопка «Открыть сверку билда»
   всегда ведёт на стабильный блок аудита; если данных нет, показывается причина
   отсутствия, а не неработающая пустая кнопка.
6. **Audit all cached summaries** сравнивает каждого игрока каждого
   кэшированного матча с нормализованным каталогом билдов. В сводке видны
   отдельные строки владельца аккаунта, союзников и соперников с reference
   build, score, ошибками, совпавшими действиями и confidence.

Неизвестные и повреждённые записи считаются пробелами покрытия. Они не
превращаются в ложные «ошибки», «idle villagers» или нулевые оценки.

## Сравнение Steam, Relic и AoE4World

Steam используется для обнаружения локальных аккаунтов и связи профиля с
SteamID64. Авторизация и загрузка ранговых/реплейных слотов выполняются через
Relic-поток, а публичные профили, игры и мета — через AoE4World. В приложении
эти источники явно маркируются и объединяются только на уровне совпадающего
игрового идентификатора. Поэтому «сравнение со Steam» не означает, что Steam
является единственным источником рейтинга: Steam — идентификатор и точка входа,
а факты матча берутся из Relic/AoE4World и локальных файлов.

В **Settings → Integrations** можно дополнительно настроить официальные Twitch
и YouTube API для поиска VOD. Ключи хранятся в защищённом хранилище Electron и
не попадают в renderer или OBS browser source.

## Реплеи и AOEMods.Essence

### Replay parser

В комплект входит локальный TypeScript-парсер командного потока. Для неподдержанного
формата сводки можно выбрать bundled/self-hosted `aoe4world/replays-api` sidecar
на `127.0.0.1` или задать `RTSLYTICS_REPLAYS_API_URL`. Внешнему endpoint передаётся
только краткоживущая подписанная ссылка, а loopback получает приватный gzip-файл.
Полный `.rec` command-stream остаётся локальным.

### Essence adapter

`AOEMods.Essence` — опциональный исследовательский источник, а не обязательная
часть запуска. Он используется для:

- инвентаризации и выборочного распаковки `.sga`;
- декодирования `.rgd` в проверяемую проекцию атрибутов;
- декодирования `.rrtex` в нативные иконки HUD/ресурсов/цивилизаций;
- сохранения provenance, ревизии и количества обработанных записей.

Сырые архивы остаются в локальном ignored staging. В runtime загружаются только
проверенные компактные проекции. Essence не заменяет AoE4World API и не является
полным парсером команд реплея.

## Архитектура и структура каталогов

```text
AOE4-Analytics/
├─ electron/
│  ├─ main.ts                 # жизненный цикл Electron и окна
│  ├─ preload.ts              # безопасный bridge без Node API в renderer
│  ├─ ipc/contract.ts         # типизированные каналы и DTO
│  └─ services/               # API, Steam/Relic, реплеи, кэш, overlay, sync
├─ src/
│  ├─ api/                    # HTTP-клиент, timeout, retry, disk cache, типы
│  ├─ data/                   # снапшоты, build orders, иконки, источники
│  ├─ domain/                 # чистые алгоритмы и парсеры без Electron/React
│  ├─ renderer/
│  │  ├─ main/screens/        # страницы вкладок
│  │  ├─ main/components/     # карточки, таблицы, overlay controls
│  │  ├─ main/queries/        # React Query и IPC hooks
│  │  ├─ overlay/             # игровой overlay renderer
│  │  └─ shared/              # UI, i18n, IPC client, форматирование
│  └─ store/                  # настройки и локальное состояние
├─ scripts/                   # sync, import, Essence и sidecar tooling
├─ data/research/             # provenance и проверенные research snapshots
├─ docs/                      # parity, TODO и проектная документация
├─ electron-builder.yml       # Windows packaging
└─ package.json               # команды, зависимости и версия
```

### Поток данных

```text
React screen
  → React Query hook
  → preload (contextBridge)
  → typed IPC channel
  → Electron main service
  → API / Steam-Relic / локальный файл / sidecar
  → cache + provenance
  → domain parser/aggregator
  → DTO обратно в renderer
```

Renderer не читает файлы напрямую и не получает секреты. Доменные функции
тестируются отдельно, поэтому сравнение билдов, civ-токены, фильтры матчей,
кэширование и replay coverage можно проверять без запуска Electron.

## Быстрый старт

Требования: Windows 10/11, Node.js `>=22`, npm и Python 3 для optional sync/
Essence-скриптов. Для аккаунтных реплеев нужен доступ к Steam/Relic; без него
работают локальные файлы и bundled snapshots.

```powershell
git clone https://github.com/ccsimplyspolit/AOE4-Analytics.git
cd AOE4-Analytics
npm ci
npm run dev
```

Для запуска уже собранного стабильного bundle используйте `npm run start`.
Откроется нативное окно `RTSLytics`; старый `python -m http.server 4173` не
запускает Electron-приложение.

Полная проверка перед коммитом:

```powershell
npm run verify          # typecheck + lint + Vitest
npm run bundle          # production Electron/Vite bundle
npm run dist            # Windows installer/portable build
npm run pack            # unpacked Windows directory build
```

Синхронизация источников выполняется явно:

```powershell
npm run sync:sources:dry
npm run sync:sources
python scripts/essence_adapter.py --status
python scripts/essence_adapter.py --auto-discover
```

После обновления снапшотов перезапустите приложение: Vite импортирует их как
bundled TypeScript/JSON-данные.

## Кэширование, повторы и границы данных

- HTTP-клиент использует таймауты, ограниченный retry/backoff и disk cache;
- запросы с одинаковым ключом разделяют результат, а явная кнопка «Повторить»
  обходит устаревший ответ и сохраняет новый успешный результат;
- summaries и `.rec` имеют отдельные кэши, чтобы повторный разбор не скачивал
  файл заново;
- локальная, публичная и Relic-история различаются в DTO и UI;
- patch/season `unknown` означает отсутствие метаданных, а не патч `0`;
- все агрегаты показывают фактический размер выборки и покрытие.

## Приватность и безопасность

RTSLytics — read-only companion. Приложение не внедряется в AoE4, не читает
память процесса, не отправляет команды в игру и не пытается обходить античит.
Локальные `warnings.log`, Steam cookies и реплеи используются только после
явного действия пользователя и хранятся в каталоге userData. Секреты API
шифруются OS secure storage. OBS получает только локальный HTTP browser source.

Пути к личным файлам, кэш, raw captions, сырые `.sga/.rec` и временные бинарники
исключены из Git через `.gitignore`. Проверенные снапшоты и provenance можно
аудировать в `data/research/`.

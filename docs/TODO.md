Осознанные границы: replay не позволяет достоверно восстановить серверное состояние, vision/scouting, назначение рабочих, неотправленные/неуспешные действия или смысл неизвестной команды; такие места показываются как unknown/inferred, без выдумывания фактов.

Осознанное отличие: произвольный пользовательский JavaScript из upstream `custom_func(data)` не выполняется. В RTSLytics оставлены bounded CSS, typed Stream Desk controls и structured casting override — это исключает выполнение кода из settings/OBS browser source.
